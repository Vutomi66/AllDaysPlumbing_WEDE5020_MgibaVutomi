## About the project
All Days Plumbing is a plumbing business in Johannesburg that offers 24/7 emergency plumbing. This website lets customers see the services, ask for a quote, and contact the business. It was built in three parts: HTML structure (Part 1), CSS and responsive design (Part 2), and JavaScript, SEO and deployment (Part 3).
